# Photos

Drop the restaurant photos into this folder using the filenames below. The
gallery on the site reads `manifest.json` and shows whatever is present —
any file that's missing is skipped automatically, so you can add them over time.

> The hero banner uses **`hero.jpg`** — use a wide, high-impact shot (the Chico
> Malo burger with chips works great).

| `chico-malo-hands.jpg` | Loaded double cheeseburger held in hands |
